# Mikrodalga Kalan Süre Pazarlık Protokolü

## Resmi (Olmayan) Beyanname

Bu repository, mikrodalga fırınınızla kalan süre konusunda yürütülen diplomatik pazarlıkların resmi protokolüdür. 

**Uyarı:** Bu kod gerçekten çalışır. Mikrodalga ise gerçekten dinlemez. Bu, insanlığın en eski sorunlarından biridir.

## Neden Bu Protokol Var?

Çünkü mikrodalga her zaman haklıdır. Siz ise her zaman yanlış süre seçersiniz. Bu protokol, bu adaletsizliği diplomasi yoluyla çözmeyi amaçlar. Çözmez ama. Ama denemek önemlidir. Çünkü bilim böyle ilerler. Ya da ilerlemez. Önemli değil.

## Nasıl Kullanılır?

```bash
python pazarlik.py 90
```

90 saniye kalan süre ile pazarlık başlatır. Mikrodalga ile 5 tur diplomasi yürütülür. Sonuç tamamen rastgeledir, tıpkı gerçek hayattaki bazı kararlar gibi.

## Bilimsel Temel

Bu protokol, şu temel prensiplere dayanır:

1. Mikrodalga bir makinedir.
2. Siz bir insansınız.
3. İnsanlar makinelere yalvarabilir.
4. Makineler dinlemez.
5. Yine de yalvarmaya devam ederiz.

Bu, modern uygarlığın özetidir.

## Özellikler

- Gerçekten çalışan Python kodu
- Abartılı diplomatik dil
- Rastgele sonuçlar (sürpriz!)
- Buzdolabı ışığı tehdidi seçeneği
- Uluslararası Mikrodalga Konvansiyonu referansları (uydurma)
- Patates içermez. Söz.

## Katkıda Bulunma

Eğer daha iyi pazarlık teknikleri biliyorsanız, pull request açın. Mikrodalga onaylamayabilir ama biz onaylarız.

## Lisans

Bu protokol, herkes tarafından kullanılabilir. Mikrodalga ise kendi lisansını kendisi belirler.
